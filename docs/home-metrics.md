# 首页入口统计

首页原先只将磁盘摘要传给顶部，工具列表一直使用默认 `HomeToolItem(detail=null)`，所以每个入口显示占位值。Debug 还默认启用了设计预览，其固定 12.5GB 会覆盖真实数据。现在 Debug 默认使用真实数据；长按标题才能显式选择设计预览或回到 Live data，旧版本自动保存的预览模式不会继续生效。本次将七个入口接到独立的真实统计。

| 入口 | 数值含义 |
| --- | --- |
| Network Traffic | 当前自然月的移动网络 + Wi-Fi 总流量；只有部分渠道可用时以 ≥ 表示下界 |
| Clear Notifications | 已配置自动清理规则的应用数量，不伪造通知的“磁盘占用” |
| Apps | 有使用情况访问权且系统支持时，显示当前用户主存储的系统应用代码 + 数据占用；缓存已包含在数据中，不再重复相加；否则显示可管理应用数量 |
| Photo Compress | 最近已完成扫描中可压缩原图的总大小，不是预计节省量 |
| Large Files | 最近已完成扫描中大文件候选的总大小 |
| Unused Files | 最近已完成扫描中至少 30 天未修改候选的总大小 |
| Screenshots | 最近已完成扫描中截图的总大小 |

文件入口取整个扫描结果，不随页面临时筛选或勾选改变。没有可用扫描摘要时显示 Scan first；完成扫描且确实为空才显示 0B。未授权/读取失败分别显示 Access needed / Unavailable。

这些入口存在交集，不能相加当成整机占用。文件值是最近扫描快照，外部新增/移动等变化需要再次扫描。照片压缩保留原图时，原图占用不会假装减少。

## 数据与生命周期

- `AndroidHomeOverviewRepository` 组合基础存储、四类扫描聚合、平台统计和通知规则，仅持有固定数量的小型值。
- 四类文件通过 SQLite 聚合最近 ready 扫描，不在首页遍历文件系统，不把未完成扫描当成结果。
- 网络复用既有模板/权限处理，只查询总量，不查询每个应用的流量 bucket。
- 应用占用使用 `StorageStatsManager.queryStatsForUser`，不逐包查询和重复累计 shared UID。系统查询串行占用一个有界 I/O 许可，不在主线程执行，不发起权限请求或轮询。
- 首页退出后取消订阅；已发出的同步系统调用返回后释放许可。返回首页保留上次界面，再通过 Diff 更新新摘要，避免整页退回 Loading。

## 清理后的联动

扫描索引升级为 v3，增加 URI/路径查询索引，保留旧数据。删除成功后按已知 URI 或实际路径同步移除各扫描快照中的同一文件，避免一个入口清理后另一个入口仍累计旧记录。媒体路径只用于缓存身份关联，实际读写仍使用获授权的 content URI。

如果从另一个入口删除了照片组参考图，剩余组会重新保护一张，并取消其待处理选择，避免留下没有参考图的分组。外部文档提供方无法建立跨 URI 身份关联时，以重新扫描结果为准。

## 验证

单元测试覆盖各入口格式、未知与零值、应用数量回退及首页取消订阅但保留上次摘要。设备测试使用独立临时数据库验证最新完成扫描、空结果、跨入口身份同步和参考图保护；平台统计只读查询，不修改权限或用户文件。

平台依据：[StorageStatsManager](https://developer.android.com/reference/android/app/usage/StorageStatsManager)、[StorageStats 数据包含范围](https://developer.android.com/reference/android/app/usage/StorageStats)。
