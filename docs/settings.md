# 设置入口

首页右上角按钮进入 `SettingsActivity`，包含语言设置、隐私协议、反馈建议、关于我们四个入口。页面复用现有浅色背景、蓝色按钮、Roboto 字体以及 Figma 原版返回/箭头和机器人 WebP。

`SettingsPage` 只封装本功能的页面框架、系统栏和键盘 Insets，不引入 Activity 基类。四项固定内容使用独立约束的 SettingsItemView；内容支持滚动和自然高度，不为静态设置页增加列表适配器或持续任务。

- 语言设置：支持跟随系统和 16 种语言，使用原生资源及 AppCompatDelegate 切换，详见 languages.md。
- 隐私协议：浏览器打开配置 URL，不嵌入 WebView、不新增网络权限、不编造隐私政策正文。没有可用浏览器时保留当前页并提示。
- 反馈建议：最多 2000 字的草稿，旋转时由 View 状态恢复。仅在点击后打开邮件编辑器，由用户确认发送；不上传、不自动发送，不附带设备标识。无邮件客户端时可以手动复制反馈。草稿不会另行写入数据库或日志。
- 关于我们：显示 APP 名称、功能简介和当前安装包的版本号/版本代码。PackageManager 查询在已有受限 IO 调度器执行，协程随页面销毁取消。

## 可配置地址

配置位置：`app/src/main/res/values/settings_endpoints.xml`。

用户指定先使用虚构地址，因此默认值为保留示例域名 `https://example.com/privacy` 和 `feedback@example.com`。这些是开发占位值，发布前必须替换为真实隐私政策和反馈邮箱。

`SettingsDestinations` 将 Intent 构造与启动分离，约束隐私链接为 HTTP(S)，验证邮箱格式并编码反馈文本，避免换行、& 和 # 改变 URI 参数。

## 验证

`SettingsDeviceTest` 验证首页入口及子页面返回、反馈草稿旋转恢复、邮件参数编码、四个入口的大字号/触控区域。测试不打开外部网页或发送邮件，不修改用户语言偏好。

## 设置图标

四个入口图标由用户明确要求使用内置 image_gen 生成，属于本次授权的 AI 原创资源，不标为 Figma 导出：当前使用 v2：统一低饱和蓝色的地球、带勾盾牌、对话气泡和信息标记，采用轻量扁平造型。首版立体图标保留为历史素材。

原图、透明切图、提示词与裁切/校验记录保存于 `design/generated/settings-icons/v2/`。保留生成 alpha，以主体边界统一裁切留白，再在开发时转换为五档无损 WebP（32/48/64/96/128px）。设置列表使用固定 32dp ImageView，标为装饰元素，不重复朗读或拦截整行按钮。原有右侧箭头和导航行为保持一致。
