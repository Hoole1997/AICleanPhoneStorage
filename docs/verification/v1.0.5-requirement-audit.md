## 新增广告点位

| Slot Key / PositionName | 调用位置 | 核对结果 |
| --- | --- | --- |
| `new_user_start_clean` | `DeviceScanActivity` / `DeviceScanViewModel` | 六项设备信息真实完成后，仅主动点击 Start Clean 请求；等待关闭/失败/无填充后进入首页；连续点击、页面重建不重复请求 |
| `uninstall_anyway` | `UninstallRetentionActivity` / `InterstitialPlacements` | 第一张挽留页 Uninstall Anyway 请求插屏，回调后进入原因页；保留 App 和原因页底部卸载按钮不追加广告 |
| `splash`（复用） | `StartupAdCoordinator` | 新用户及卸载快捷入口继续经过原开屏；推送点击继续开屏→首页→功能，不新建开屏 Key |

两个新点位均实际传给现有 `InterstitialActions` / `loadInterstitial`，并经过 `AdSlotSwitchController.isEnabled(positionName)`，没有仅声明未调用的遗漏。广告 SDK 内部负责广告请求/展示统计，不新增重复的业务模拟广告曝光。

第 6 节两行明细均为插屏，1.1.1 也明确“不新增开屏广告位”；文末数量表却把 v1.0.5 写为开屏 1、插屏 1。按明细核对后应为新增插屏 2；截至 v1.0.5 为 **开屏 1、插屏 34、原生 24，共 59 个 Key**。其中 56 个实际入口、1 个条件位、2 个预留结果页位。本地 `docs/ads/slots.md` 原有 55/52 的历史统计和“测试强制放行”说明已修正，未改远端文档或广告后台。

## 功能核对与用户覆盖规则

| 需求部分 | 当前实现及结论 |
| --- | --- |
| 新用户流程 | 独立 Activity + XML；真实品牌/型号、系统、分辨率、密度、内部存储及引擎初始化，不扫描文件；前后台暂停/恢复、Unknown 和 Retry 已接入。退出重走按用户选择的 1.1.5，不采用 1.1.4 冲突描述 |
| 卸载挽留 | 买量用户 + paid.enabled 动态 Shortcut，经过启动页复核；独立 Activity + XML，六个入口复用原权限/扫描流程；原因/反馈仅点击底部按钮时按最新授权上报，原因页卸载按钮进入本 App 的系统应用信息页，再由用户在系统页操作；贷款文案已按用户确认替换 |
| 八种场景 | 1101–1108 的通知 ID、来源和路由独立；CoreService 注册/释放；点击消费及字段缺失兜底已实现。原 FCM/日龄推送不加入新队列、不共用新间隔 |
| 触发间隔 | 每场景整数分钟；无新场景每日总上限。截图无额外等待/URI 去重，其他固定确认延迟按最新要求 1 分钟。充电开始防抖此次从 5 分钟改为 1 分钟 |
| 展示队列 | 只保存尚未展示事件，同场景最新候选；FIFO，当前整轮循环及尾部窗口结束再交棒；出队前校验，首条成功后不因原始事件变化中断循环；不设置排队过期 |
| 通知文案/动效 | 单句 HTML text，b/strong 仅加粗，font 显式指定颜色，本地默认强调片段为红色；远程可配置、按条件轮播。新旧按钮均补齐增强 XML 呼吸、双层水波纹及单向扫光；图标继续原版资源呼吸 |
| 开机 | 静态 BOOT_COMPLETED + 已有权限声明，Provider 单次请求 CoreService；复用 10001 常驻，权限未开跳过，不自动开页/扫描；真实重启验证见 boot-and-grouping.md |
| Grouping | 配置激活及统一接口就绪后，由启动页观察；离开页面停止观察。晚于页面退出的配置下次进入启动页处理，不后台补报 |

## 剩余差异与平台边界

- 文档 3.2.1 写“分别提供普通、深色图标版本”；当前是原 Figma 透明素材配固定白色通知内容底板，没有独立夜间图标资产。没有把同一资源改名冒充两个设计版本；这项仍不是文档字面的独立夜间版本。
- Android 14 截图 API 仅在对应 Activity 可见时回调，不能用于后台全局截图检测。本任务按用户指定 CoreService 监听，使用有权限的 MediaStore 元数据，不把前台 API 当作后台能力。[Android 官方说明](https://developer.android.com/about/versions/14/features/screenshot-detection)
- 无可靠证据时不猜 Wi-Fi 漫游/新 AP、其他用户的应用状态或私有缓存；通知本身不能保证系统一定显示悬浮横幅。
- 新广告位远端开关、广告平台 ID/填充与 Firebase/数数线上收数未在本轮改动或验收；客户端调用、参数、去重和路由已核查。
