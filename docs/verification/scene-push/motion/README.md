# 整句富文本与 XML 动效修正

2026-10-22，依据用户提供的 `飞书20261022-034951.mp4`（26.84 秒）以及最新指示实现。原视频只用于观察，不复制为应用素材。

## 文案

新场景唯一正文协议：`"text": "<b>Charging started!</b> View status."`。本地 27 条默认文案、翻译字段、变量替换、前台提示、系统标准正文、自定义 RemoteViews 和点击快照均使用同一完整正文。

没有 `title/desc` 配置兼容分支。每份 RemoteViews 只有一个 `sceneText` TextView，红色粗体只来自 `b/strong` 标记；普通片段使用常规字重。屏幕窄或字体大时允许自然换行，不在两个片段之间插入换行。新场景没有系统内容标题；为保留已有埋点协议，`title` 为空，`text` 保存完整纯文本。旧推送的标题/正文协议没有改动。

## 动效

- 按钮：原生 XML AnimatedVectorDrawable + objectAnimator。900ms 连续小幅呼吸，1200ms 高光单向完整扫过；离开右侧后从左侧重新进入，不在中间来回折返。高光按按钮圆角裁切。
- 图标：沿用原版 WebP，48 个 XML 缩放帧组成 960ms 平滑循环，没有原来末帧 750ms 的停顿。
- 箭头：原版素材，32 个 XML 位移帧组成 960ms 平滑循环，不缩放或重绘箭头图案。
- 动画由原生 ProgressBar/Drawable 承载，不启动 App 帧定时器、不重复 notify、不逐帧生成或解码大图。按钮绘制边界跟随文字自然宽高，避免折叠态默认 48dp 测量造成背景过窄。
- 关闭动效/省电时使用静态分支；已验证可见内容隐藏后 Animatable 停止。
