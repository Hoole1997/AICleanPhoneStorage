# 首页动效

按用户最终要求，AI 机器人和 Smart Clean Now 边框流光共用 2.8 秒时间轴，无间隔循环。

- 机器人做约 3dp 的轻微悬浮及不到一度的摆动，只改变 RenderNode 的 translationY/rotation。
- 光带沿胶囊按钮真实 PathMeasure 周长移动，覆盖约 20% 边框；首尾接缝连续，按钮中心、文字与图标不被覆盖。
- Shader、Path、Paint、Matrix 和坐标数组复用，不逐帧解码图片、创建位图或执行实时模糊。按钮仍是 MaterialButton，原生 Ripple 和点击即时生效。
- 页面后台、窗口失焦（包括弹框）、列表滚动/卡片不可见、系统关闭动画、省电或触摸探索开启时停止。停止后取消 Animator、还原属性；系统设置监听只在 resumed 期间注册。

构建、Lint 和既有 53 项单元测试通过。设备测试验证流光不改变尺寸/文字区域/点击行为，以及后台和滚出视口后机器人还原。未用这些测试代替真实机型的帧率和耗电测量。
